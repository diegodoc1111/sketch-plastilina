# Sketches de plastilina con Claude Code y Blender

Guía gratis en español de [@soydiegoosorio](https://instagram.com/soydiegoosorio): https://diegodoc1111.github.io/sketch-plastilina/

## Fuentes verificadas (4-nov-2026)
- Instalación de Claude Code: https://code.claude.com/docs/en/setup (Pro, Max y superiores; el plan gratis no lo incluye).
- Blender 5.2.3 LTS para Windows y Mac (Apple Silicon): https://www.blender.org/download/
- ElevenLabs: plan gratis con 10.000 créditos al mes (~10 min de voz); clonación instantánea desde Starter: https://elevenlabs.io/pricing
- Skill de sketches de plastilina: https://github.com/santmun/sketch-plastilina
